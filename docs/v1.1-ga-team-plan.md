## §0 为什么另开 v1.1 plan（不写进 v1.0 GA plan）

2026-08-30 用户裁定 B 路径：
- **v1.0 runtime = 鱼鳞 kernel GA**（Python kernel，5 周）→ 走 `docs/v1.0-ga-team-plan.md`（已 frozen）
- **v1.1 product = 鱼之产品 GA**（手机派工 + 6 host + 语音 + dsh wrapper）→ 走本文 v0.0 draft

**为什么不能合一份**：v1.0 runtime 目标是 "Python kernel 包化 + CI + 容器部署"，v1.1 product 目标是 "手机派工 + 6 host + dsh wrapper"——前者代码 = Python + 已有 spike 资产，后者代码未来 = TypeScript + 外部 dsh 依赖 + 新能力域（语音 / Web Push / 多 host）。两阶段任务书、验证清单、风险、回滚完全不同。**合成经验教训**：v0.6 / v1.0 总纲合成导致事实错乱、章节引用错位、未验证假设被焊成守门（详见 `docs/ARCHITECT-REVIEW-fish-harness-prd-v1.0.md`）。
