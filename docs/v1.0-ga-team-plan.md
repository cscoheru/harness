## Context

fish-harness v0.9.5 已合并到 `main`（HEAD `10a5c96`），交付物 = `spec/` + `ADR/` + `spikes/m0/`（13 spike，5627 行）+ 1 个 CI workflow。Codex 复审 PASS / 28/28 反例 / 17/17 mutation / 10/10 Protocol。但**无 production runtime**：仓库无 `pyproject.toml`、无 `harness/` package、无 Dockerfile、无 deploy workflow、无 human review gate。

v1.0 GA 的任务 = 把 v0.9.5 从"形式验证完毕的 spec baseline"升级为"可生产部署的 runtime"。架构师只做规划、派发、最终验证。所有实现由 5 个角色 Agent 承担。
